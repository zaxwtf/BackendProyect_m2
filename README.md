# API Whishlist

Proyecto del Módulo 2 — Full Stack Dev Bootcamp.

## Qué es

una API para gestionar inicios de sesión, agregar juegos favoritos, deseados, en colección y poder borrarlos también de cada categoría

## Stack

- Node.js + Express
- MongoDB + Mongoose
- JWT para autenticación
